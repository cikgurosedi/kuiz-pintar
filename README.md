# Kuiz Pintar

Projek kuiz interaktif untuk membantu pelajar mengulang kaji dan menguji kefahaman.

## Kursus
SMN20193 Elektro Pneumatik dan Elektro Hidraulik

## Objektif Projek
- Membina kuiz mengikut topik.
- Menyediakan soalan aneka pilihan.
- Memaparkan markah secara automatik.
- Membantu pelajar belajar secara interaktif.

## Status Projek
Dalam pembangunan.
